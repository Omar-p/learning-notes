### What is JVM(Java Virtual Machine)?
- it's the runtime VM in which a java program is run.
- Take the compiled Java bytecode and run it.
- Has a specification that outline how it should work.
- Different implementations available.
- Essential in making Java platform agnostic. (if any new hardware architecture released since someone can build a jvm on top of it according to the specification, you can execute your java program on this hardware)

### What is JRE(Java Runtime Environment)?

  - Libraries and Utilities.

### What is the difference between permgen and metaspace?
- Memory Areas in the JVM.
- Before Java8, there was a memory area called PermGen.
- Java8 onwards, this is called Metaspace.
- PermGen is gone!
- PermGen had a fixed max size allocated (configurable)
- Metaspace expands as needed by default.
  - Has maxMetaSpaceSize configuration(if u want to behave like permgen, having a fixed size). Triggers garabage collection when hit.
- both related to the area where JVM load the bytecode and all the things that necessary to execute the code.
- Because of class loading/unloading. no "permanent generation" anymore.
  - with PermGen, there is no unloading of classes.
    - if class is loaded in permGen, it lasts forever.(now, it;s not permanent anymore).

### What is grabage collection?
- Process of removing unused and orphaned objects from the heap.
- Automatic Process. Does not need programmer intervention.
- Has APIs to trigger programmatically(not recommended).
- Generation based approach.
  - younger & older & permanent (https://stackoverflow.com/a/2129294)
- Benefits - no manual memory management.
- Drawback - performance intrusion.

### Equality and the Equal method?
- Set - no duplicate elements
- `contains` method - `o == null ? e == null : o.equals(e)`
- check if the same ref, same class, compare fields(use Objects.equals for nullable ones)
- Rules:
  - Reflexivity
    - any object should be equal to itself
  - Symmetry
    - x.equal(y) then y.equals(x)
  - Transitivity
    - x == y, y == z, then x == z
  - Consistency
    - return same result unless the object state has been modified.
  - Non-nullity
    - an object should never be considered equal to null.

### Hashing:
- the process of mapping data of arbitrary size to fixed-size values or keys, known as hash codes, that represesnt the original data in a way that can be easily and quickly looked up. 
- use cases:
  - password storage
  - file integrity checking
  - digital signatures
  - Caching, lookup for key.
- When two objects are equal according to the `equals` method, they should also have the same hash code.
- options:
  - Default - generate a hash code based on the memory address
  - Use a unique memeber variable.
  - Generate a hash based on a combination that's unique.

### Iterator

- iterator not tolerant to underlying changes.
